# 模板分享使用指南

## 功能介绍

模板分享功能允许用户将创建的模板分享给其他用户使用，实现模板的协作和复用。

## 使用方法

### 1. 分享模板

在模板列表页面（`/templates`）：

1. 找到要分享的模板
2. 点击"分享"按钮
3. 在弹出的对话框中选择要分享的用户
4. 点击"确定"完成分享

### 2. 查看分享的模板

在模板列表页面，可以查看：
- 自己创建的模板
- 其他用户分享给你的模板

### 3. 使用分享的模板

- 分享的模板可以查看和使用
- 不能修改分享的模板
- 如需修改，可以复制模板后进行编辑

## API 接口

### 分享模板
```http
POST /api/templates/{template_id}/share
Content-Type: application/json

{
  "user_ids": [1, 2, 3]
}
```

### 获取分享给我的模板
```http
GET /api/templates/shared/me?skip=0&limit=100
```

### 获取模板的分享用户列表
```http
GET /api/templates/{template_id}/shares
```

## 权限说明

### 分享者权限
- 只有模板创建者可以分享模板
- 可以随时修改或取消分享
- 可以查看分享记录

### 被分享者权限
- 可以查看分享的模板
- 可以使用分享的模板生成报表
- 不能修改分享的模板
- 不能再次分享

### 权限控制
- 分享是单向的，不会影响原模板
- 取消分享后，被分享者无法再访问模板
- 已生成的报表不受影响

## 注意事项

- 分享前请确认模板内容不包含敏感信息
- 建议定期清理不再需要的分享
- 分享的模板会显示创建者信息
- 被分享者无法查看模板的版本历史

## 最佳实践

### 1. 模板命名规范
- 使用清晰的名称描述模板用途
- 包含业务场景信息
- 例如：`月度销售报表-华东区`

### 2. 模板描述
- 详细说明模板用途
- 列出数据源和查询条件
- 说明更新频率

### 3. 分享管理
- 定期检查分享列表
- 及时取消不再需要的分享
- 使用用户组进行批量分享（未来功能）

## 常见问题

### Q: 如何取消分享？
A: 重新打开分享对话框，清空用户列表后点击确定即可。

### Q: 被分享者能看到模板的 SQL 吗？
A: 可以，被分享者可以查看完整的模板配置，包括 SQL。

### Q: 分享的模板被修改了怎么办？
A: 被分享者看到的始终是最新版本。如需保留特定版本，建议使用版本控制功能。

### Q: 可以分享给所有用户吗？
A: 可以通过设置模板为公开模板实现，公开模板对所有用户可见。
