# 图表智能字段推断功能设计

## 概述

在图表展示后，根据 SQL 查询结果自动推断并关联 X 轴、Y 轴字段，同时允许用户手动调整字段映射并实时更新图表。

## 需求背景

当前 ChartViewer 需要用户手动输入 X 轴、Y 轴字段名，不够直观。期望：
1. 用户输入 SQL 后自动推断字段
2. 图表下方显示字段映射供调整
3. 调整后图表实时更新

## 功能设计

### 1. 字段推断规则

| 图表类型 | X 轴推断 | Y 轴推断 |
|---------|---------|---------|
| 折线图/柱状图 | 第一列（字符串类型优先） | 数值类型列（int/float/decimal） |
| 饼图 | 第一列 | 数值类型列 |
| 散点图 | 第一个数值列 | 第二个数值列 |
| 雷达图 | 第一个字符串列 | 数值类型列 |
| 仪表盘 | - | 数值类型列 |
| 漏斗图 | 第一列 | 数值类型列 |

**规则细节**：
- 如果没有数值类型的列，Y 轴默认选择第二列
- 如果查询结果只有 1 列，X 和 Y 都使用该列
- 如果查询结果为空，不进行推断

### 2. 后端改动

#### 2.1 查询接口返回字段信息

修改 `/api/v1/query/execute` 接口，在返回结果中增加 `columns` 字段：

```json
{
  "success": true,
  "data": {
    "columns": ["store_name", "sales", "profit"],
    "column_types": ["VARCHAR", "DECIMAL", "DECIMAL"],
    "rows": [...]
  }
}
```

#### 2.2 图表生成接口接收字段映射

修改 `/api/v1/chart/generate` 接口：
- 请求中增加可选字段 `field_mapping`: `{ "x_axis": "store_name", "y_axis": "sales" }`
- 如果未提供，使用后端自动推断

### 3. 前端改动

#### 3.1 ChartViewer.vue

**新增状态**：
- `queryResult`: 存储 SQL 查询结果（包含 columns）
- `fieldMapping`: 存储当前字段映射 `{ x_axis, y_axis }`

**新增逻辑**：
1. 用户点击"预览数据" → 执行 SQL，获取列名列表
2. 根据推断规则设置 `fieldMapping`
3. 图表渲染时使用 `fieldMapping` 的值
4. 图表下方显示"字段映射"区域：
   - X 轴下拉选择器（选项：所有列名）
   - Y 轴下拉选择器（选项：所有列名，数值类型优先）
   - 用户切换选择器后**立即重新渲染图表**

**UI 布局**：
```
┌─────────────────────────────────────┐
│  配置表单（数据源、SQL、图表类型等） │
├─────────────────────────────────────┤
│  [预览数据] [生成图表]              │
├─────────────────────────────────────┤
│  字段映射：                         │
│  X 轴: [▼ store_name    ]          │
│  Y 轴: [▼ sales        ]          │
├─────────────────────────────────────┤
│  📊 图表展示区域                     │
│                                     │
└─────────────────────────────────────┘
```

#### 3.2 ChartRenderer.vue

**无需改动**，props.config 中已支持 x_axis、y_axis。

### 4. 数据流

```
用户输入 SQL
    ↓
点击"预览数据" → 调用 execute_sql API
    ↓
后端返回 { columns: [...], rows: [...] }
    ↓
前端根据 columns 推断 fieldMapping
    ↓
显示字段映射选择器（带默认值）
    ↓
用户点击"生成图表"（可选：也可直接生成）
    ↓
调用 generate_chart API（传入 field_mapping）
    ↓
后端使用传入的字段映射（或自动推断）
    ↓
返回图表配置 → 前端渲染
    ↓
用户调整字段映射 → 重新渲染图表
```

## 错误处理

- SQL 执行失败：显示错误信息，不显示字段映射
- 列名为空：显示提示"无法获取字段信息"
- 选择的字段不存在于结果中：使用推断的默认值

## 验收标准

1. **预览数据功能**：输入 SQL 点击预览后，SQL 执行并返回列名
2. **智能推断**：预览后自动选中合理的 X/Y 轴字段
3. **字段调整**：下拉选择切换字段，图表立即更新
4. **兼容性**：手动输入字段名的旧流程仍然可用

## 影响范围

- 后端：query_service.py - execute_sql 返回 columns
- 后端：chart_service.py - generate_chart 支持 field_mapping
- 前端：ChartViewer.vue - 新增预览功能 + 字段映射选择器
